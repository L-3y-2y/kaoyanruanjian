# 背单词软件 · 完整版（考研 / 四六级 / 高考）

按 `docs/需求与设计骨架.md`（v0.6.7）实现的**前后端完整版**，阶段 0～5 全部落地；后来又加入**多书籍切换**与**情景式背词 A/B/C**。
技术栈按文档定稿：**Vue 3 + Vite / Python + FastAPI / MySQL 8.0 / 浏览器 speechSynthesis**。

所有运行时数据都在同一个库 **`kaoyanruanjian`** 里，用的是只被授权了这一个库的账号 `kaoyan_app`；数据库凭据与大模型 Key 只在 `backend/.env`，不进 Git、不下发浏览器。

---

## 一、怎么用

**第一次**：双击 `setup.bat`（建 Python venv、装依赖、构建前端）。本次交付已经跑过，**不用再点**。

**以后每次**：双击 `start.bat` → 浏览器打开 **http://localhost:8000**。

后端启动会自动执行幂等的表结构迁移 + 词库补齐，重复启动不会重复插数据、不会丢进度。
启动窗口不会回到提示符（服务正在跑），**别关**；要停按 `Ctrl+C`。

**账号**：默认「本机模式」，打开就能用，进度存在占位账号 `local` 里。点右上角「切换账号」→ 注册，**已有的学习进度会自动归到新账号名下，一条不丢**。注册后各账号的进度、短文、答卷互相隔离。想强制登录，把 `backend/.env` 的 `LOCAL_MODE` 改成 `0`。

## 三、实现了什么

### 学习主流程（一次学完 5 轮）
- 每天用滑轴自选 N（1～100），只能从「未掌握池」取词；每 5 词一小周期，最后一组不足 5 也正常结束（N=18 → 5/5/5/3）
- **R1 认词**：只给英文，点「陌生」才展开读音+释义，再点「认识」才过
- **R2 听音默写**：听读音拼写，可反复重播；答错显示正确单词，**重新输入时答案消失**
- **R3 看义默写**：看中文 + 读音默写英文
- **R4 看词写义**：写汉义 → 看标准答案 → 自评「记住了 / 没记住」
- **R5 看义默写**：再看中文默写英文；走完 5 轮 → **「已学完」**，自动进复习池
- 学完 5 轮即可解锁每日短文（无需等背熟）
- 状态用 `memorized_at`（学完 5 轮）/ `mastered_at`（复习背熟）两个独立时间戳；进度只存服务端；改进度 + 写答题记录同一事务；防重复提交；大小写/空格归一化；中文 utf8mb4

### 复习（艾宾浩斯遗忘曲线）
- 学完 5 轮的词自动进复习池，按 **1 / 2 / 4 / 7 / 15 / 30 天** 间隔到期召回
- 每次复习过**三轮**：① 认不认识 → ② 听音默写 → ③ 汉译英默写；三轮走完该词间隔 +1
- 6 个间隔全部走完 → **「已背熟」（mastered）**，从此不再出现
- 复习中不认识 / 拼错 → 该词间隔归零，明天再来
- 学习与复习界面的词右上角都有**「熟知」按钮**：点一下直接标「已背熟」，跳过之后一切学习和复习

### 账号与隔离（阶段 4）
- 开放注册 / 登录 / 登出；`password_hash` 存 **pbkdf2-sha256 200k 轮 + 随机盐**，绝不存明文
- **Session-Cookie**（HttpOnly / SameSite=Lax / 30 天），服务端从 cookie 解析身份，不信前端传的 user id
- 所有业务 SQL 带 `user_id` 过滤：进度、批次、短文、题目、答卷全部隔离
- 首个注册账号自动接管本机旧进度（一次性、事务内完成）
- `admin` 表 + 管理员登录；管理员只管词库（新增/修正词条、检索、来源统计）。本机模式可直接试用，多用户环境下严格限管理员

### 多书籍（考研 / 四级 / 六级 / 高考）
- 导航栏「英语 AI」右侧的「书籍」下拉切换；四本书的**进度、词池、短文、阅读、AI 出题完全隔离**。同一个词（如 approach）同时在多本书的词库里，但每本书各自从零学起，互不串进度。
- 数据结构：`book` 表存考试类型与 ECDICT 标签；`daily_plan / progress / article / answer_log / chat_session` 都带 `book_id`；唯一键重建为 `(user, book, word, round)` 等，`user.current_book_id` 记住当前书。
- 老数据全部归到 book 1（考研英语），迁移脚本 `scripts/migrate_books.py` 幂等，已跑完且无损。
- 四条生成链路都按当前书注入考试类型与词汇范围：短文、周阅读题目、AI 助教、练习卡；**不覆盖各考试专属题型**（那是二期），目前是难度+词汇适配。
- 词库按 ECDICT 天然标签过滤，一个词可属于多本书，不复制词条。

### 语境填空（今日学习必经关卡）
- R1 认识 → R2 听写 → R3 默写 → R4 汉译英 → R5 英译汉 五轮全部通过后，进入 **语境填空关卡**，从今日词里均匀抽最多 5 个词。
- 每个词配 1 个 10～25 词真题风格短句，按 `(词, 书)` 懒生成并缓存；挖空后自己填入单词，答错可重试，附中文提示。
- **必须全部填对才算完成今日学习**：此时才写 `memorized_at`、进入艾宾浩斯复习池（1/2/4/7/15/30 天）并解锁每日短文。答案只存服务端，前端在答对前拿不到。
- 短文沉浸直接复用「每日短文」页；图片联想方案已取消。

### 每日短文（阶段 5 · A1～A7）
- **学完 5 轮（已学完）后出现**；按「用户 + 日期批次」持久化，重复进入是同一组，绝不重新生成
- 全放优先：每篇 12 词、最多 3 篇；超过容量走**抽词**，优先错得多的词并轮转（`sample_cursor`），**未收录词明确列清单告知**
- 首次渲染**纯文本，无任何可点元素**，今日词与其它词外观完全一致
- 底部按钮「显示今日词」→ 按 `article_word` 包可点元素，点词显示**生成时的释义快照**；**揭示是每次手动触发的，不落盘**，刷新后回到纯文本（可再点一次显示）。释义快照一直存在，不会丢
- 词形还原用 ECDICT `exchange` + 规则兜底：复数 / 过去式 / 句首大写 / 短语动词都能点
- 已生成的文章可用「用大模型重新生成」按钮重写正文（需配 Key）；**不写回 `progress`**

### 每周阅读理解（阶段 5 · B1～B5）
- 固定 **2 篇**，每周五 **18:00** 发布、周日 23:59 截止；后台每 10 分钟真定时 + 打开页面兜底补生成，另有 `scripts/weekly_publish.py` 可挂计划任务
- 本周词 = 本周内**背熟（mastered）**的批次取并集；放不下就抽词并告知未收录词
- 每篇 5 题：主旨 / 词义猜测 / 细节 / 推理四选一 + 1 道简答题
- **客观题直接比对标准答案**；**简答题走 AI 判分**，判分理由存 `answer_log.ai_result`
- 答卷、成绩按「用户 + 周次」保存；逾期可补做但**不计成绩**；防重复提交
- 页面上「提前生成本周（试用）」可在周五 18:00 前立即体验（只生成本人那一周）

### 场景化、语境小测与英语 AI 助手
- **场景化短文**：进入批次前可选「校园 / 实验室 / 职场 / 新闻 / 旅行」，场景写进 `article.scene`，只影响尚未生成的批次；已生成的短文绝不重写。
- **语境小测**：短文揭示后自动从已标注词里取最多 5 个做成完形填空题，干扰项来自同批次词，答错当场显示释义快照。纯前端练习，不写数据库、不改进度。
- **英语 AI 助手**：导航「英语 AI」可问任意英语问题——中翻英、英翻中、查单词（释义/音标/搭配/例句）、语法分析、作文润色都支持；还能一键用**今天学的词**出考研风格练习：**「选词填空 · 交互」「阅读理解 · 交互」会生成可点选的题卡**——文章里的空/每道题直接是下拉框或单选按钮，点完提交就即时判分、逐空逐题看中文解析，还支持「就这题问 AI」继续追问；题卡存在对话历史里，答完可接着用文字聊天，对话能力完全不受影响。另有英译汉、考研大/小作文走文字出题 + 批改。出题时会主动剔除你正在看的文章语境，并把已有短文/阅读的标题与摘要作为"禁止复用"清单，保证练习是全新文章，不会把原文挖空。题卡判分纯前端完成、不消耗 token，**完全旁路**——不写 `progress`/`answer_log`。短文「问 AI · 这篇文章」、周阅读逐题「问 AI」会额外带上真实语境快照，但**不局限**于这篇文章。最多 8 轮，普通回复 512 token、出题/批改自动放宽到 1200 token（可用 `CHAT_PRACTICE_TOKENS` 调）。**完全旁路**——不写 `progress`/`answer_log`、不计入五轮状态。需配 Key。

## 四、词库与生成层

**词库已按四本书导入完成**：`word` 表共 **7,395 词**。各书按 ECDICT 标签过滤，一个词可同时属于多本书：

| 书籍 | 标签 | 词数 |
| --- | --- | --- |
| 考研英语 | `ky` | 4,803 |
| 四级词汇 | `cet4` | 3,755 |
| 六级词汇 | `cet6` | 5,311 |
| 高考词汇 | `gk` | 3,616 |

导入只做 `INSERT IGNORE`，原有词的 id 不变，已有 `progress` 引用完全不受影响。ECDICT 词标记 `source='ECDICT-ky'` 或 `'ECDICT-exam'`、`verified=0`，按当年大纲抽查核对后再标 1（需求 B1 的正确性兜底）。重新导入 / 预览：

```
backend\.venv\Scripts\python.exe scripts/import_ecdict.py
backend\.venv\Scripts\python.exe scripts/import_books.py --dry-run
backend\.venv\Scripts\python.exe scripts/import_books.py
```

**大模型是可选增强**：`llm.py` 把 `generate_text(prompt)` / `generate_json(prompt)` 做成配置化的一层，主源 + 兜底都从 `.env` 读，不写死模型名；短文、周阅读题目、主观题判分共用这一层。

**推荐免费源：智谱 GLM-4-Flash**。官方标「完全免费」、国内直连、OpenAI 兼容，中文写作与长上下文都比 Agnes 免费档更对口；Agnes 免费档只限速流（约 10～20 次/分钟）、没有 SLA，留作兜底正合适。`glm-4.7-flash` 虽然更新，但实测晚高峰常返回 429「访问量过大」，所以默认用更稳的 `glm-4-flash`。智谱 Key 在 https://open.bigmodel.cn 注册后到控制台创建，不用绑卡。把下面几项填进 `backend/.env`（`LLM_API_KEY` 必填，兜底可留空）后重启：

```
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_API_KEY=你的智谱Key
LLM_MODEL=glm-4-flash
LLM_FALLBACK_BASE_URL=https://apihub.agnes-ai.com/v1
LLM_FALLBACK_API_KEY=你的AgnesKey
LLM_FALLBACK_MODEL=agnes-3.0-flash
```

**生成链已加固**：短文要求模型返回 JSON（标题 + 正文），用与「点词释义」完全相同的词形还原表校验覆盖率；漏词会带着缺失清单重写一次，仍不达标才退回本地生成器（不再硬塞 `The word X also belongs...` 这种机械句子）。周阅读的 5 道题也改为模型按文章内容一次生成（4 道四选一 + 1 道简答及评分要点），格式不合法或调用失败才回退旧模板。主观题判分结果按「参考答案 + 作答」缓存，重复提交不再消耗免费额度。

**界面上可切换模型**：顶部状态条（显示「已接 · 具体模型名」或「本地生成」）点一下，弹出模型面板。里面只允许在服务端预置的几个模型间选——接口地址和 Key 永远留在服务端、不发送到浏览器。切换立即生效、无需重启，并写回 `.env` 持久化。面板里的「测试当前模型」会真发一句极简请求，直接告诉你这个模型此刻能不能用（避免「显示已接、实际限流」却看不出来）。候选名单可用 `LLM_MODEL_PRESETS` 在 `.env` 里自定义（逗号分隔的模型名）。

没填 Key 时实际运行的是本地确定性生成器：短文仍保证 100% 覆盖、可点，题目用模板，判分按要点覆盖率给分。免费政策会变，用前到各家官网核实。

## 五、管理员与定时任务（可选）

> **没有预置管理员账号，也没有默认密码。** 交付时 `admin` 表是空的（0 行），密码不由程序代设、不经手任何人，因此不存在「账号密码是多少」这回事。
>
> **在这台电脑上你根本不需要它**：`LOCAL_MODE=1`（默认）时，回环地址的请求落到本机账号 `local`，`require_admin` 对本机模式直接放行 —— 打开页面就有「词库管理」页签，能检索、新增、修正词条，无需任何登录。

只有需要**正式的管理员登录**时才创建，例如要从别的设备访问、或把 `backend\.env` 里改成 `LOCAL_MODE=0` 强制所有人登录：

- 最省事：双击 `setup_admin.bat`
- 或在项目根目录执行：

```
backend\.venv\Scripts\python.exe scripts\create_admin.py
```

按提示输入用户名（直接回车用 `admin`）和**你自己设的密码**两次（至少 8 位、不回显、不落盘，只存 pbkdf2 哈希）。之后页面「切换账号」→「管理员」登录即可。忘掉密码就重跑一次同名覆盖，不影响任何学习数据。

管理员权限仅限词库三件事（统计 / 检索 / 新增修正词条），**看不到别人的进度、短文和答卷**。

周五晚定时由后端自动跑；想再挂一层 Windows 计划任务，用 `scripts/weekly_publish.py`（文件头有 `schtasks` 示例命令）。两条路都幂等，不会重复生成。

## 八、排错

| 现象 | 原因 | 怎么做 |
| --- | --- | --- |
| `start.bat` 闪退 / venv missing | 没跑过 `setup.bat` | 先跑一次 |
| 浏览器打不开 8000 | 服务没起来 | 重新双击 `start.bat`，别关窗口 |
| `Access denied for user 'kaoyan_app'` | `.env` 密码不对 | 改成你当初设的密码（别发给任何人） |
| 页面显示「后端未连通」 | 后端没启动 | 先启动后端再刷新 |
| 每日短文里没有批次 | 还没学完 5 轮 | 去学习板块把 R1～R5 走完 |
| 周阅读显示「尚未发布」 | 没到周五 18:00 | 点「提前生成本周（试用）」，或等定时任务 |
| 提示「未掌握池只剩 0 个词」 | 当前这本书的词都学完了 | 切到别的书，或重跑 `import_books.py` 由管理员加词 |
| 中文变问号 | 连接没走 utf8mb4 | 检查库/表字符集；`db.py` 已显式指定 |
| 一天想重选 N | 一天只能建一条计划 | 接口返回 409；明天再来 |

## 九、已知边界（如实说明）

- 未配置大模型 Key 时，短文与阅读题目由**本地确定性生成器**产出（句式模板 + 目标词），不是大模型写的自然语言文章；配置 Key 后同一条链路自动切换到模型生成并做覆盖率校验与补词。
- 读音是浏览器 `speechSynthesis` 合成音（文档 B2 定稿），不是真人音频。
- ECDICT / 词书都是社区整理，不是官方大纲原文；`verified=0` 表示尚未人工核对。
- 本机模式只对回环地址生效且默认开启，适合自用；`LOCAL_MODE=0` 可强制所有请求先登录。
